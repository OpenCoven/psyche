## First executable task

Start [#11](https://github.com/OpenCoven/psyche/issues/11) with the experimental `psyche.intent.v1` schema. [#50](https://github.com/OpenCoven/psyche/pull/50) owns the sixteen canonical vectors and their digest index. Draft [#60](https://github.com/OpenCoven/psyche/pull/60) proposes intent as a stable-v1 target. The #11 owner still needs to select the publication surface. Work from the current typed contract in `crates/psyche-core/src/contracts/intent.rs`, the `decode_document` entrypoint in `crates/psyche-core/src/contracts/mod.rs` and the intent fixture in `crates/psyche-core/tests/fixtures/intent-local.json`. After bootstrap and the fast gate, run `cargo test --locked -p psyche-core --test decode` for the baseline.

Add a Draft 2020-12 schema and a focused parity test. Check the [pinned #50 intent vector](https://github.com/OpenCoven/psyche/blob/2c6eb2a51677f601908120da3f57cffc4d11747d/crates/psyche-core/tests/fixtures/vectors/psyche.intent.v1.json) and its [SHA-256 entry](https://github.com/OpenCoven/psyche/blob/2c6eb2a51677f601908120da3f57cffc4d11747d/crates/psyche-core/tests/fixtures/vectors/SHA256SUMS) against both the schema and the typed decoder, preserve its exact canonical bytes and digest, and exercise unknown fields, wrong ID prefixes, unsupported major versions and malformed input. Document any validation that belongs to the parser or requires Rust semantics. The slice is ready for review when the positive and denial corpus passes offline in both implementations and the required G2 evidence is linked. Closing #11 additionally requires published representations for fencing, cancellation acknowledgement and unresolved outcomes, and result/artifact binding, or an explicit owner decision revising that minimum. The selected surface also needs reproducible publication and a pinned downstream compatibility and rollback canary.
